# 📝 To-Do List App  
A minimal, dark-mode to-do list built with HTML, CSS, and JavaScript. It lets you add, complete, and delete tasks with localStorage ensuring your tasks persist between sessions. Clean UI, smooth interactions, and easy to use—tasks can be added by clicking the button or pressing Enter.

🚀 Features  
> Add, complete, and delete tasks  
> Tasks persist using localStorage  
> Dark mode design with responsive layout  
> Keyboard-friendly (supports Enter key)

🔧 Technologies  
> HTML  
> CSS  
> JavaScript (Vanilla)
